# DLSS MFG Manager v1.7.0

## Türkçe

Bu sürüm ana ekranı sağlanan launcher referanslarına daha yakın bir yapıda yeniden düzenler.

- Seçili oyun üstte tam genişlikte bir hero/vitrin alanında gösterilir.
- Oyun adı, görsel durumu ve kurulum bilgisi vitrinin soluna yerleştirildi.
- Frame Generation ayarları ayrı ve kompakt bir karta taşındı.
- Görsel yenileme, başlatma, kurma ve kaldırma işlemleri sağda dikey launcher eylemleri olarak düzenlendi.
- Oyun kütüphanesi vitrinin altına taşındı ve pencere genişliğine göre 3–5 sütunlu görsel galeriye dönüştürüldü.
- 980×680 pencere boyutunda kart başlıkları, durumlar ve işlem düğmeleri görünür kalır.
- Geniş oyun görsellerinin kart yazılarının arkasına taşması düzeltildi.

> Yalnızca çevrimdışı ve tek oyunculu oyunlarda kullanın. Anti-cheat veya çevrimiçi oyunlarda proxy DLL kullanmayın.

## English

This release restructures the main screen to follow the supplied launcher references more closely.

- Displays the selected game in a full-width top hero.
- Places game identity, artwork state, and installation state on the left.
- Moves Frame Generation settings into a dedicated compact card.
- Presents refresh, launch, install, and removal as vertical launcher actions on the right.
- Moves the library below the hero as a responsive 3–5 column visual gallery.
- Keeps card titles, states, and all actions visible at 980×680.
- Prevents wide artwork from painting behind card title and status areas.

> Use only with offline, single-player games. Do not load proxy DLLs in anti-cheat or online games.
