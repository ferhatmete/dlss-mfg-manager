# DLSS MFG Manager v1.9.1

## Türkçe

- **Seçili Oyunu İnternette Kontrol Et** artık Türkçe arayüzde Türkçe Google dil/bölge ayarlarını kullanır.
- Arama sorgusuna oyun adıyla birlikte `uyumluluk`, `kurulum` ve `Türkçe` ifadeleri eklenir.
- İngilizce arayüzde İngilizce arama korunur.
- Seçili olmayan sol menü ve ikincil işlem düğmeleri artık açık gri dolgu ve ince kenarlıkla belirgin görünür.
- Mor renk yalnızca aktif menü veya birincil işlem durumunu belirtir.

## English

- **Check Selected Game Online** now follows the interface language.
- Turkish UI uses Turkish Google language/region parameters and Turkish compatibility/setup terms.
- English UI keeps an English search query.
- Inactive navigation and secondary action buttons now have a visible light fill and border.
- Purple remains reserved for the active navigation item or primary action.
