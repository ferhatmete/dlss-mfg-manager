# DLSS MFG Manager v1.4.2

This maintenance release fixes the two usability issues reported in the redesigned library.

## Fixed

- The game list now responds reliably to the mouse wheel and Page Up/Page Down even though the native bright scrollbar remains hidden.
- Steam's larger wide background artwork is preferred over the smaller header image.
- Artwork is rendered in a proportional top hero area, avoiding excessive zoom and cropping.
- Long game titles and executable paths no longer widen the details card or push buttons beyond the right edge.
- Refresh Artwork and all three main action buttons remain visible at the minimum 1100×720 window size.

## Safety

Use this application only with offline, single-player games. Do not use proxy DLL files with anti-cheat or online games. Compatibility must be checked for each game using current external information.
