# DLSS MFG Manager v1.4.0

## Türkçe

- Uygulamanın tamamı klasik Windows aracı görünümünden modern oyun launcher düzenine geçirildi.
- Sol gezinme menüsü, aranabilir oyun kütüphanesi ve geniş oyun görseli/hero alanı eklendi.
- Frame Gen paket işlemleri, güvenlik uyarısı ve dil seçimi kalıcı sol menüde birleştirildi.
- Oyun tarama, desteklenen kartlar ve oyun kataloğu pencereleri aynı mor-siyah degrade ve yuvarlatılmış kart stiline taşındı.
- 1100×720 minimum boyutta ana işlem düğmelerinin metinleri tam görünür.

> Yalnızca çevrimdışı/tek oyunculu oyunlarda kullanın. Anti-cheat veya çevrimiçi oyunlarda kullanmayın. Her oyunun güncel uyumluluğunu ayrıca kontrol edin.

## English

- Rebuilt the entire application from a conventional Windows utility into a modern game-launcher layout.
- Added a persistent sidebar, searchable library, and wide selected-game hero area.
- Unified package controls, safety warning, and language selection in the sidebar.
- Restyled discovery, supported-GPU, and game-catalogue dialogs with the same purple-black gradient and rounded cards.
- Primary action labels remain fully visible at the 1100×720 minimum size.

> Use only with offline/single-player games. Do not use in anti-cheat or online games. Always check current per-game compatibility.
